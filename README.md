# Using-the-Danish-Registers

## Purpose

This repository is for users of Statistics Denmark (DST) research server access under Michael E. Benros. The servers give us access to a copy of the Danish registers, and our primary DST project is `708237`.

The repository contains user guides and documentation for working with the registers and for exporting results from the DST servers for use in publications.

## Guidelines

1. [DST server behaviour guidelines](server-export/DST-server-behaviour-guidelines.md) describes best practices for working on the DST servers.
1. [DST and SDS register overview](pre-processing/DST-and-SDS-register-overview.md) describes important aspects of key registers intended for new users of the registers.
1. [DST server export guidelines](server-export/DST-server-export-guidelines.md) describes how to export results from the DST servers.
1. [Population description](/population/2022-10-21 Documentation of Register Populations on DST Project 708237.docx) describes the generation of the full Danish population on from various registry sources (**outdated**).
    a. Note that this documented is **outdated**, but it still describes relevant considerations about working on the registers. 
    b. A new population is in use and its description is work in progress. 
    c. For the time being, users with DST server access are guided to [DST and SDS register overview](pre-processing/dst-and-sds-register-overview.md) for further information.
